## 🆘 Troubleshooting

### "npx: command not found"
**Solution:** Install Node.js from https://nodejs.org

### "Permission denied"
**Solution:** On Mac/Linux, try:
```bash
sudo npx vercel --prod
```

### Need to login?
Vercel CLI will automatically open browser to login. Just follow the prompts!

### Deployment stuck?
Press `Ctrl+C` and try again. Network issues are rare but can happen.
